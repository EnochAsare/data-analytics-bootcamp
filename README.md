My learning journey through Alex the Analyst's Data Analytics Bootcamp, featuring hands-on projects in Excel, SQL, Power BI, and Python.

# WHY AM I TAKING THIS BOOTCAMP?
I enrolled in Alex the Analyst's Data Analytics Bootcamp to build a strong foundation in data analytics through practical, hands-on learning. My goal is to develop the technical and analytical skills needed to solve real-world business problems, create meaningful insights from data, and prepare for internship and career opportunities in data analytics. This repository documents my learning journey, projects, and progress throughout the bootcamp.

# LEARNING OBJECTIVES
Throughout this bootcamp, I aim to:
-Develop strong SQL skills for querying, cleaning, and managing databases.
-Master the fundamentals of Excel for data analysis and reporting.
-Create interactive dashboards and visualizations using Power BI.
-Learn Python for data cleaning, analysis, and automation.
-Build a portfolio of real-world data analytics projects.
-Follow Git and GitHub best practices for version control and project documentation.
-Strengthen my problem-solving and critical thinking skills using data.
-Prepare for data analytics internships and entry-level analyst roles by showcasing practical, well-documented projects.
